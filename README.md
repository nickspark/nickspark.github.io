# Zhe Wang academic homepage

Static academic homepage inspired by [academic-homepage](https://github.com/luost26/academic-homepage). Open `index.html` directly in a browser to preview it. The Publications link opens the full publication list in `publications.html`.

## Publish with GitHub Pages

1. Create a GitHub repository, ideally `<your-username>.github.io` for a root-domain site.
2. Push `index.html`, `publications.html`, `styles.css`, `script.js`, `assets/`, and `.nojekyll` to the repository root on the `main` branch. The `resume_latex/` directory and resume ZIP are not needed for the public site and contain personal information.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/(root)`.
4. GitHub will show the published URL. A repository named `<your-username>.github.io` appears at `https://<your-username>.github.io/`; another repository appears at `https://<your-username>.github.io/<repository-name>/`.

No build step or hosting service is required. All site asset paths are relative, so both GitHub Pages URL formats work.
